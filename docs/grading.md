# Assessment summary (v5)

- **Common Core: 80 points** — requirements, design, baseline, React/API integration, v1.1 change, tests, PR/CI/CD, security/operations, portfolio/evidence.
- **Individual Engineering Improvement: 20 points** — student-owned, scoped improvement with spec, tests, review and release trace.
- Extra credit (up to 20) at instructor's discretion.

The authoritative rubric remains the v5 teaching handout. This sheet is a navigation aid, not a substitute.
